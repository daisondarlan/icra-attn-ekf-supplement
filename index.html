Attention-Gated EKF and Confidence-Gated PID for Fault-Tolerant UAV Altitude Hold

Specular lidar returns can appear statistically normal while reporting incorrect altitude values. A standard Kalman filter cannot easily detect this type of error. This work introduces a softmax confidence signal derived from the Kalman innovation. This signal adapts the measurement covariance and is directly routed into the proportional gain of the altitude-hold PID controller. On a continuous flight benchmark with a lidar-bias fault, this approach reduced fault-window tracking error by 82.1% and the associated thrust-error spike by 84.1%. A mathematical bound ensures the controller remains stable for all confidence values.

03Live Simulator

Fly the same dual-arena benchmark yourself

Download and run the headless backend, then connect this page to your session over MQTT to observe both arenas in real time.

The dashboard needs a running backend to show live drones. It connects over MQTT to a small Python physics engine, which is meant to run for free in a Google Colab notebook. Loading this tab alone will not move any drones — follow the three steps below first.
  1. Download the backend script below and paste the whole file into a single Google Colab cell. A T4 GPU runtime is enough, and a CPU runtime also works, just a little slower.
  2. Run the cell. It prints a line telling you it is waiting for a session to connect, and it picks a random session ID for you.
  3. Type that same session ID into the connect box in the embedded dashboard below, then press Connect. The two flight arenas should start moving within a few seconds.
